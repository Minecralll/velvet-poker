# Проверка Velvet Poker 0.3

Дата: 31 октября 2026.

## Подтверждено в этой версии

- 4 проверки Cloudflare (Node.js + реальный workerd/Miniflare): 4 независимых клиента, WebSocket-аутентификация, создание и вход по коду, дружба, закрытые карты, повторная доставка действия без повторного списания, полная раздача и сохранность общей суммы фишек.
- Перезапуск Cloudflare-процесса во время живой раздачи: клиенты переподключаются, хост остаётся с той же колодой и ставит игру на паузу. Отдельно проверено восстановление при перезапуске всех клиентских контекстов, сохранность друзей и метаданных SQLite.
- Проверки API: лимит 4 участников, запрет пятого, чужие почтовые ящики, запрет незашифрованных пакетов, подмена хоста, сессии, порядок публикаций, смена ключа гостя, доступ по токену, приглашения только друзей.
- Подтверждено отсутствие постоянного HTTP-опроса: на клиент идут один HTTP health-запрос и регистрация, затем WebSocket.
- 7 прежних JS-проверок движка и совместимости с Python-ретранслятором прошли после добавления нового транспорта.
- Отдельный Chromium-тест против Miniflare: 4 браузерных профиля, реальные формы создания и входа, колл/чек/флоп, справочник без подсказки текущей руки, потеря сети у хоста, блокировка гостя, переподключение, пауза, восстановление карт после reload, продолжение таймера, выход хоста. Ширины 320/360/390/768/1100 без горизонтального переполнения и перекрытия личных карт столом.
- Для локального браузерного стенда отключалась проверка LocalNetworkAccessChecks, блокирующая WebSocket к localhost после перехвата HTML тестовым маршрутом. Это исключительно флаг тестового Chromium, не настройка приложения или публичного сервиса.
- Wrangler 4.156.0 собрал Worker через deploy --dry-run, binding CLUB определён как SQLite Durable Object. Реальной публикации эта команда не выполняла.
- APK собран Android Build Tools 35.0.0 / API 35 / Java, versionCode 3, versionName 0.3.0, minSdk 26, targetSdk 35.
- apksigner подтвердил v2/v3-подпись; zipalign пройден. Сертификат совпадает с APK 0.2: обновление можно ставить поверх.
- Встроенные JS-файлы APK побайтно совпадают с исходниками, transport.js включён в allowlist WebView, CSP допускает WSS. Адрес по умолчанию: https://velvet-poker.darkminecralll.workers.dev .

## Не проверено / ограничения

- APK не запускался на физическом Android или Android-эмуляторе.
- Публичный Worker пользователя не обновлён из этой среды. В начале работы адрес отвечал Hello World. Для работы требуется установка cloudflare/DEPLOY_WINDOWS.cmd или wrangler deploy владельцем аккаунта.
- Реальные мобильные сети, задержки между странами и квоты аккаунта Cloudflare пока не измерены.
- Gradle/lint и GitHub Actions workflow здесь не запускались; APK собран альтернативным скриптом из tools/build_apk.py.
- Сохранение хоста остаётся на исходном устройстве; экспорт и перенос роли хоста не добавлены. Старые профили с другого сервиса не мигрируют автоматически.
- Прежние 49 Python-проверок версии 0.2 в этом цикле не повторялись: правила не менялись. Текущая проверка обратной совместимости использовала реальные HTTP-клиенты и Python-сервер.
