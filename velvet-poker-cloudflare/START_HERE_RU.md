# Velvet Poker 0.3 — установка сервиса Cloudflare

Адрес, встроенный в APK:
https://velvet-poker.darkminecralll.workers.dev

На момент подготовки пакета по этому адресу находилась заглушка Hello World.
Пакет сам по себе не загружен в ваш аккаунт. Для запуска нужно выполнить установку ниже один раз.

## Windows — самый короткий путь

1. Установите Node.js 24 LTS с https://nodejs.org/ . Оставьте стандартные настройки установщика.
2. Полностью распакуйте архив Velvet_Poker_0.3_Cloudflare_Server.zip в отдельную папку. Не запускайте скрипт прямо внутри ZIP.
3. Откройте папку `velvet-poker-cloudflare` и дважды нажмите `DEPLOY_WINDOWS.cmd`.
4. Дождитесь установки инструментов. Откроется браузер: войдите в тот аккаунт Cloudflare, где создан `velvet-poker`, и разрешите Wrangler управлять вашими Workers.
5. Если предложен выбор аккаунта, выберите тот же аккаунт. Если Wrangler предупреждает о замене существующего Worker `velvet-poker`, это ожидаемо: заменяется созданная ранее заглушка Hello World.
6. Дождитесь строки с опубликованным адресом. Имя Worker должно остаться `velvet-poker`; поддомен аккаунта — `darkminecralll`. Если получился другой адрес, передайте его для изменения APK.
7. Откройте https://velvet-poker.darkminecralll.workers.dev/health . Должен появиться JSON с `ok: true`, `protocol: 3`, `phone_host: true`, `transport: "websocket"`.
8. Установите APK 0.3 на все телефоны. Войдите под разными именами, создайте стол на телефоне хоста, отправьте другу код. Ноутбук теперь можно выключить.

Скрипт НЕ переводит аккаунт на платный тариф, не добавляет карту и не меняет DNS домена. Он устанавливает серверный код и SQLite Durable Object из `wrangler.jsonc`.
Если Cloudflare требует оплату, остановитесь и передайте текст ошибки: нужен именно Workers Free и SQLite, не устаревшее KV-хранилище Durable Objects.

## Вручную / macOS / Linux

В терминале из распакованной папки:

```sh
npm ci
npx wrangler login
npx wrangler deploy
```

Либо `sh deploy.sh`. Вход выполняется в браузере Cloudflare. Пароли и API-токены никому отправлять не нужно.

## Что размещается

- Один Worker `velvet-poker`.
- Один класс SQLite Durable Object `VelvetClub`, binding `CLUB`.
- Одна общая инстанция клуба: `velvet-private-club-v1`. Не менять имя, если нужны прежние профили/комнаты.
- Профили, хеши ключей входа, друзья, приглашения, состав комнаты, открытые ключи, краткая сводка комнаты сохраняются в SQLite.
- Зашифрованные пакеты, очередь и сессии хостов — в оперативной памяти. Перезапуск сервиса не теряет колоду: хост публикует состояние из своего сохранения и ставит активную раздачу на паузу.
- Вся игровая логика, карты и полное сохранение остаются на телефоне хоста. При его уходе игра останавливается.

Это интернет-ретранслятор, не прямой P2P. WebRTC/STUN/TURN здесь не нужны: телефоны сами открывают исходящее защищённое WebSocket-соединение. Для них не требуется открывать порты роутера.

## Бесплатные ограничения

На 31 октября 2026 документация Cloudflare указывает: Workers Free — 100 000 запросов/сутки; Durable Objects Free — 100 000 запросов/сутки, 13 000 GB-секунд/сутки, 5 ГБ SQLite, отдельные лимиты чтения/записи.
Смотрите текущие условия: https://developers.cloudflare.com/durable-objects/platform/pricing/

Чтобы уменьшить расход, приложение держит один WebSocket на игрока, объединяет повторные проверки и получает уведомления об изменениях. Для неизменившейся сводки SQLite не перезаписывается. Установлены лимиты регистрации, друзей, комнат и сообщений. Это частный клуб, а не масштабируемая публичная покерная платформа.

Один объект использует обычные WebSocket-соединения (без hibernation), чтобы хранить временные зашифрованные очереди без постоянных записей в SQLite. Продолжительность учитывается за всё время открытых соединений: для одной инстанции максимум около 10 800 GB-секунд за полные сутки при тарифицируемых 128 МиБ. Квоты общие с другими приложениями аккаунта. Не создавайте дополнительные копии класса/инстанции ради каждой комнаты. Реальные квоты публичного аккаунта в этой сессии не измерены; бесплатную работу при любой нагрузке пакет не гарантирует.

При исчерпании квот Workers Free операции могут завершаться ошибкой до сброса лимита. Приложение при потере связи сохраняет стол на паузе. Контролируйте Usage в панели Cloudflare; переходить на Paid для этой установки не нужно.

## Проверка / обновление

В полном архиве исходников есть тесты:

```sh
npx wrangler deploy --dry-run --outdir build
npm test
```

Для обновления кода повторите `npx wrangler deploy` из папки обновлённого проекта. Не удаляйте Worker, класс или namespace, чтобы не потерять серверные профили. Не меняйте адрес сервиса без миграции: адрес входит в область локального хранения APK.

Старые профили с отдельно запущенного Python-сервера автоматически сюда не переносятся. Данные на телефоне не стираются обновлением APK, но доступны при выборе прежнего адреса сервиса. Не удаляйте приложение для установки обновления.

## Если не работает

- `Hello World!` на `/health`: наш пакет ещё не опубликован или установлен в другой аккаунт.
- Ошибка Node.js: нужен Node.js 24 LTS; откройте терминал заново после установки.
- Ошибка входа/аккаунта: выполните `npx wrangler logout`, затем `npx wrangler login` и войдите в нужный аккаунт.
- HTTP 1101/ошибка сервиса: передайте текст ошибки из Cloudflare Workers Logs, предварительно убрав личные данные. Токены профиля или Cloudflare присылать не нужно.
- Хост не в сети: он должен открыть приложение и свой сохранённый стол. Продолжение после обрыва — вручную через меню стола.

APK собран и проверен по подписи. На физическом Android пока не тестировался. Вход по коду и игровой обмен проверены четырьмя независимыми клиентами в локальной среде Cloudflare; публичный аккаунт ещё требует установки.
