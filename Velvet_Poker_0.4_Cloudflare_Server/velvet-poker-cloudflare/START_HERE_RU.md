# Velvet Poker 0.4 — обновление Cloudflare

Адрес приложения: https://velvet-poker.darkminecralll.workers.dev

## Уже подключён GitHub: что сделать

1. Распакуйте `Velvet_Poker_0.4_Cloudflare_Server.zip`.
2. Откройте свой репозиторий https://github.com/Minecralll/velvet-poker . На главной странице файлов выберите **Add file → Upload files**.
3. Перетащите **всю папку `velvet-poker-cloudflare`** из архива. Она должна заменить прежнюю одноимённую папку, а не оказаться внутри неё. ZIP загружать не нужно. Нажмите **Commit changes**.
4. Cloudflare соберёт новую версию через уже подключённый репозиторий. Существующие рабочие настройки сборки оставьте: команда развёртывания `npx wrangler deploy`, корневая папка проекта `velvet-poker-cloudflare` (в вашей панели путь может отображаться с начальным `/`).
5. Дождитесь успешного Deployment. Откройте https://velvet-poker.darkminecralll.workers.dev/health . В JSON должны быть `version: "0.4.0"`, `economy_version: 1`, `protocol: 3`.
6. Установите `Velvet_Poker_0.4_Club.apk` **поверх старой версии на всех телефонах**. Не удаляйте приложение и не очищайте его данные: полное сохранение стола находится у хоста.
7. Откройте прежний стол. В старом сохранении подарки выключены: хост может включить их между раздачами через **⋯ → Подарочные фишки**. В новых комнатах они включены.

В этой сессии подготовлен пакет и выполнены локальные тесты. Новый код в ваш аккаунт Cloudflare автоматически не опубликован.

## Что добавлено

- Серверный баланс косметических баллов, покупки и экипировка, история использования промокодов.
- 30 эмоций; 16 цветов и 16 рисунков карт; 8 персонажей и 16 цветов костюмов.
- +1 балл за принятый ручной чек, колл, ставку/рейз или олл-ин. Пас, блайнды, таймер, просмотр магазина и повтор доставки команды баллов не дают.
- Баллы магазина и игровые фишки комнаты — разные балансы. Ничего не покупается за настоящие деньги.
- Общий код **VELVET100** — 100 баллов, один раз на профиль.
- Личный код на 1 000 000 000 баллов выдан отдельным файлом владельцу. В этом архиве только его SHA-256. Личный код можно активировать один раз во всём клубе; не публикуйте его в GitHub.
- Эмоции ограничены одним сообщением в 3 секунды. Игрок может скрыть их локально.

## Если хотите установить с компьютера без GitHub

Из этой папки, с установленным Node.js 24:

```sh
npm ci
npx wrangler login
npx wrangler deploy
```

На Windows также можно запустить `DEPLOY_WINDOWS.cmd`, на Linux/macOS — `sh deploy.sh`.

## Сохранность данных и связь

Не меняйте Worker `velvet-poker`, binding `CLUB`, класс `VelvetClub`, миграцию `v1` и имя инстанции `velvet-private-club-v1`. Новые SQLite-таблицы создаются рядом со старыми без очистки профилей, друзей и комнат. Адрес сервиса входит в ключ локального сохранения — оставьте прежний адрес.

Телефон хоста остаётся главным источником игровой логики, колоды и сохранения. Cloudflare передаёт зашифрованные игровые пакеты через WebSocket и хранит профили, друзей и косметику. Это ретрансляция через Cloudflare, а не соединение без серверов. Когда хост закрывает или сворачивает приложение, стол сохраняется на паузе. Автоматической передачи хоста нет.

Начисление баллов использует сохранённые на телефоне накопительные счётчики и серверные отметки уже начисленного. Повтор, задержка или перезапуск не начисляют одни ходы дважды. Цены, владение предметами и промокоды проверяет сервис. Сам хост считается доверенным: изменённый клиент хоста может подделать игровые результаты/счётчики. Это система для частной игры друзей, не независимая защита от читов.

Проект использует SQLite Durable Objects. Он не переключает тариф и не добавляет карту; расход облачных ресурсов зависит от лимитов вашего аккаунта. Существующие бесплатные настройки аккаунта оставьте. Код не создаёт отдельный Durable Object для каждой комнаты.

## Ошибки

- `Failed: root directory not found`: в GitHub проверьте, что `package.json`, `wrangler.jsonc` и `src` действительно лежат в папке `velvet-poker-cloudflare`, на которую указывает корень сборки.
- На `/health` версия 0.3: новый Deployment ещё не опубликован либо загружены файлы не в рабочую папку.
- «Обновите сервер … для магазина»: сначала завершите обновление Cloudflare, затем повторно откройте APK.
- После обрыва связи: хост открывает прежний стол и нажимает «Продолжить».
- APK не устанавливается как обновление: передайте точный текст ошибки; не удаляйте старое приложение с сохранениями.

APK подписан прежним тестовым ключом. Сборка и подпись проверены; физический Android в этой среде недоступен. Игровой интерфейс и четыре сетевых клиента проверены в Chromium с локальным Cloudflare runtime.
